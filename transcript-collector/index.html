Updating from 010: Close the collector, extract this ZIP into the existing application folder, and replace application files. Keep your GriffinShepherdLibrary folder. Start / Resume preserves saved transcripts and waits through a one-hour cooldown for the old HTTP 429.

  1. Extract the whole ZIP on your Windows PC.
  2. Double-click START_HERE.bat in the extracted folder.
  3. Follow the Python 3.12 installation instructions if prompted.
  4. Open Settings and enable authorized online downloads. Click Test automatic caption access once; it checks up to five new recordings and stops immediately if access is blocked.
  5. Click Start / Resume to collect permitted captions across the remaining catalog and transcribe available local audio. Progress is saved automatically.
