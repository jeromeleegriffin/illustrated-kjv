Current cumulative Windows package; supersedes Build 010.

UPDATING YOUR INSTALLED BUILD 010
1. Close the collector normally.
2. Extract this ZIP into the existing collector application folder.
3. Choose Replace files when Windows asks. Keep the existing .venv folder.
4. Do NOT delete or replace your separate GriffinShepherdLibrary data folder.
5. Double-click START_HERE.bat. The title should say 011.
6. Click Start / Resume once. It preserves saved transcripts.

A legacy HTTP 429 gets a one-hour cooldown starting when first resumed in 011.
The visible status shows the wait. Leave the app open and the computer awake.
Requests then run one lesson at a time, at least 60 seconds apart.
The adapter requests only one English track (en), not en plus en-orig.
Further HTTP 429 events use increasing cooldowns; after three events automatic
requests stop for investigation. Login, CAPTCHA and HTTP 403 blocks remain held.
No proxies, cookies, account switching or block bypass are used.
The cooldown is an engineering default, not a promise of YouTube access.
