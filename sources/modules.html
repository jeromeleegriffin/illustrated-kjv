Installing

SWORD — the shared format behind Xiphos, BibleTime, And Bible (Android), PocketSword (iOS) and Ezra. Unzip the file into your SWORD library folder: on Linux and Windows that is usually ~/.sword/, on Android put the unzipped mods.d and modules folders inside the app's SWORD folder. Restart the program and the commentary appears under Commentaries.

MyBible — the Android app by Denis Popov. Unzip the file and copy the .SQLite3 inside it to your MyBible data folder (usually Android/data/ua.com.smartpost.mybible/files/ or the folder the app names under Downloads → module folder). It shows up under Commentaries.

e-Sword — the free Windows program by Rick Meyers. Unzip the file and copy the .cmti inside it into e-Sword's resources folder, then restart e-Sword and the commentary appears in the Commentary pane. This is the current HTML-based module format, so it needs a recent e-Sword rather than one of the older RTF-era versions.

A note on what is here, and what is not

These are the commentaries whose copyright has expired — the nineteenth-century expositors and the fathers — so they are yours to copy, share and build on. A few sets on the website are published there by the permission of their present publishers, and permission to read something on a website is not permission to hand out copies of it, so those are deliberately not in this list.
